# Quantum mechanics lessons

Interactive lessons published with GitHub Pages. The landing page contains no lesson directory; share individual lesson URLs with students.

To add another page, create `lessons/<topic>/index.html` on `main`. Its URL will be `https://lidyalaw00.github.io/quantum-mechanics-lessons/lessons/<topic>/`. Add `<meta name="robots" content="noindex, nofollow, noarchive">` to its `<head>` if you want to discourage search indexing.

Pages and repository files are public. Anyone who has a URL, or browses this repository, can view the lessons. Use a platform with access control for restricted materials.
