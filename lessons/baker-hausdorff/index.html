The Baker–Hausdorff lemma

Why do nested commutators appear in the time evolution of quantum operators? What do they actually tell us about the motion?

Start with the Heisenberg picture, then see how a familiar Taylor expansion answers both questions.

01 · The problem

How does an operator evolve?

In the Schrödinger picture, the state evolves with time. In the Heisenberg picture, we keep the state fixed and transfer the time evolution to the operator.

|ψ(t)⟩ = e−iĤt/ℏ|ψ(0)⟩Â(t) = eiĤt/ℏ Â(0) e−iĤt/ℏ

Now we want to actually calculate Â(t). At first glance, this looks easy: the two exponentials are inverses of each other.

eiĤt/ℏ e−iĤt/ℏ = I

So why not just cancel them and get Â(t) = Â(0)? The problem is that Â(0) is sitting between the two exponentials.

If Â(0) commutes with Ĥ, it also commutes with the exponentials of Ĥ (which are built from powers of Ĥ). In that case, we can rearrange the expression:

02 · Where the nesting comes from

A Taylor expansion for operators

We have seen that cancellation works when Ĥ and Â commute. But if they do not commute, we need another way to evaluate the original expression for Â(t).

The Baker–Hausdorff lemma gives us a way to expand this expression:

eX̂ Â e−X̂ = Â + [X̂, Â]+ 1/2! [X̂, [X̂, Â]] + ···

Here, X̂ = iĤt/ℏ. To understand why nested commutators appear, start with something familiar: the Taylor expansion.

For an ordinary moving particle, we can describe its position using its initial position, velocity, acceleration, and higher derivatives:

x(t) = x(0) + v(0)t + ½a(0)t² + ···

03 · What it tells us

When does an operator not evolve?

If an operator commutes with the Hamiltonian, [Ĥ, Â] = 0, its first time derivative is zero. All the higher nested commutators also vanish.

[Ĥ, Â] = 0   ⇒   Â(t) = Â(0)

For example, the Hamiltonian itself commutes with itself. This is why energy is conserved for a time-independent Hamiltonian.

By contrast, an operator that does not commute with Ĥ changes with time. Its evolution is described by the nested-commutator series.

Lesson complete

Nested commutators are successive time derivatives.

The Baker–Hausdorff lemma is essentially a Taylor expansion for quantum operator evolution. The first commutator tells us how the operator changes, and higher nested commutators tell us how those changes develop with time.

The Hamiltonian generates time evolution. For a conserved observable, the commutator vanishes. For a nonconserved observable, the series describes how it changes with time.
